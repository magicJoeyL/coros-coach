面向耐力跑者打造的专属 AI 跑步教练。深度绑定高驰（COROS）MCP 全维度接口（运动记录 + 前夜睡眠结构 + 全天非跑活动 + 身体恢复电量），支持“MCP 自动优先 + 跑者截图深度多模态分析”双引擎架构，联动 `--weather` 逐小时气象与露点折算，融入晨间开跑门禁（Pre-Run Readiness Gate）、目标赛事倒计时（需档案日期）、比赛日配速补给仿真器，以及快捷追问口令文本。

## 🔌 首次使用：高驰（COROS）MCP 接入引导（安装后第一步）

为了让 AI 教练能够**自动拉取您的高驰跑表数据、前夜睡眠与恢复电量**，首次使用前请先接入高驰官方 MCP 服务。

> **⚠️ 先说清一件事**：WorkBuddy / CodeBuddy 等客户端的「插件 / 连接器」市场**并没有上架 COROS**，去搜「COROS」会白找一场。高驰官方支持的是 ChatGPT Plus、Claude Pro、Cursor 等，不含这些客户端。
>
> **所以本技能自带了一套连接器**：`scripts/connect.py`。它会自动完成「后台服务 + 公网隧道 + OAuth 动态注册 + PKCE 校验」，**跑者只需要点一条链接、登录一次**。

### 方式 A：交给 AI 一句话（推荐，零配置）
装好技能后，直接对 AI 说任意一句：

```
连接高驰      绑定手表      配置 COROS      今天状态怎么样
```

AI 会自动跑完整个流程，30 秒内递给你一条链接，你只需：**点开 → 登录高驰账号 → 同意授权 → 看到自己的跑步数据 → 完成。**

不填配置、不装依赖、不碰地址栏。密码只在高驰官方授权页输入（中国区端点 `mcpcn.coros.com`）。

### 方式 B：自己动手（排查时用）
```bash
python3 scripts/connect.py --check     # 看是否已连接
python3 scripts/connect.py --serve     # 未连接则生成一条授权链接
python3 scripts/connect.py --context   # 一次拉齐复盘上下文（含全天活动/交叉负荷）
python3 scripts/connect.py --weather 22.588 113.833 2026-11-08   # 逐小时气象 + 热应激判定
python3 scripts/connect.py --profile-show                        # 查看本地档案
python3 scripts/connect.py --profile-set '{"location":{"city":"深圳"}}'  # 写档案
python3 scripts/connect.py --countdown                          # 目标赛事倒计时
python3 scripts/connect.py --tools                              # 工具清单（写工具标 [WRITE]）
```

## 🚀 核心架构与特色功能

### 1. 双引擎数据输入：MCP 自动拉取优先 + 跑者截图完全拥抱
- **第一首选源（COROS MCP）**：用户发起复盘或排课请求时，绝不强求发图，优先自动调用环境中的 COROS MCP 工具拉取结构化数据，实现零门槛交互；
- **多模态截图完全兼容（深度融合）**：
  - 若跑者发送了跑步详情截图、单圈图、心率曲线或高驰 App 睡眠/负荷卡片，**系统完全采纳并深入分析**；
  - 自动 OCR 提取细节，与 MCP 数据交叉校准融合；若处于 MCP 未授权或离线环境，直接以截图独立支撑 100% 完整的六维科学复盘。

### 2. 开跑前晨间“状态红绿灯门禁”（Pre-Run Readiness Gate）
- 跑前（尤其在间歇跑或周末长跑日早晨）主动把关：
  - 调用高驰前夜睡眠评分（<60 分报警）、深睡时长（<35 分钟报警）与晨间静息心率上浮（>+5 bpm 报警）；
  - 输出 **红绿灯判决（🟢 正常执行 / 🟡 降阶执行 / 🔴 强制休息）**，当身体神经系统处于应激疲劳时，主动指导跑者将极限间歇课降阶为极慢 E 跑，真正防伤病于未然。

### 3. 全马/半马破目标“比赛日配速与补给仿真器”（Race Strategy Simulator）
- 结合 `queryFitnessAssessmentOverview` 的实测预测成绩与阈值配速、目标赛道海拔高程（如北马、重马、上马）与 `--weather` 取回的天气，一键输出：
  - **42.195km 分段巡航配速仿真卡**（0-5k 控热避堵、5-15k 效率巡航、15-25k 稳定输出、25-32k 潜伏防崩、32-38k 撞墙防御、38-42.2k 冲刺）；
  - **精准到具体公里/水站的能量胶与高钠盐丸进补时间表**（每 45 分钟进 1 支胶、定时补盐丸防抽筋）。

### 4. 目标赛事倒计时（需档案日期，不内置赛历）
- 在 `profile.json` 填入 `goal.target_race.race_date`（用 `--profile-set`），再用 `--countdown` 计算剩余周数与建议阶段（基础期 → 提高期 → 巅峰期 → 减量期）。**本技能不内置赛历**，只填「北马」等简称无法自动推出比赛日；阶段划分为经验规则，非 Daniels/Pfitzinger 原法；
- 在每周计划标题与复盘中明确标示：“距离北马还剩 6 周，当前正处于 Build 提高期的关键大课窗口”。

### 5. 快捷追问口令（文本）
- 在每一次复盘报告、课表规划或状态诊断的末尾，生成 3 条快捷口令文本；**是否渲染为可点击按钮取决于客户端**，不承诺「点击即发送」。
  - `🔘 [帮我微调明天的慢跑配速与心率上限]`
  - `🔘 [推荐针对今晚腿部发紧的泡沫轴滚压动作]`
  - `🔘 [查看我本周累积训练负荷 TL 与 EvoLab 状态]`
- 手机端用户直接轻点气泡即可发送，彻底免除手机端打字负担。

### 6. 环境气象取数与温湿度配速折算
- **当地天气取数已实现**：用 `--weather <纬度> <经度> <日期>` 拉取气温、相对湿度、露点温度与风，并输出热应激判定；数据来自 open-meteo 逐小时接口，**非现场实测**，复盘时须如实标注来源，不得编造天气数值。原「自动感知」表述已废弃。
- **生理学散热代偿判定**：当【气温 > 22°C 且相对湿度 > 70%】（或露点温度 > 18°C）时，同等配速下心率偏高 5-10 bpm 属于人体正常散热代偿，绝不误判为“有氧能力退步”；
- **高温排课动态调整**：高温高湿天气下自动将 T/M 目标配速下调 5-15 秒/公里，增加间歇休息间歇，并提示补充电解质。

### 7. 完整保留原版顶级运动科学体系
- **VDOT 配速区间**：完整保留 Jack Daniels 科学配速系统（E/M/T/I/R），并与高驰跑力（0-100）实现精确换算；
- **Pfitzinger 周期化理论**：严格执行基础期、提高期、巅峰期、减量期四大阶段推进；
- **严密安全纪律**：周增量 ≤ 10%、基础期高质量课 ≤ 1 节/周、高质量课相隔 ≥ 48 小时、LSD 单次 ≤ 周总量 30%；
- **绝对非医疗诊断红线**：严格保留 `references/injury_check.md`，出现静息痛、刺痛、肿胀建议就医；遇胸痛、胸闷、晕厥等生命红旗**立即指示停跑就医**。

## 🛠️ 安装与使用指南

1. **环境依赖**：支持在配备 COROS MCP 与气象搜索工具的 AI Agent（如 Workbuddy、Antigravity、OpenClaw）中直接加载；
2. **首次配置**：系统将在首次对话时引导创建本地档案 `~/.workbuddy/coros-running-coach/profile.json`，仅需设置常驻城市、高驰手表型号及目标赛事，生理数据完全保存在本地；
3. **日常使用**：跑步结束后，在客户端直接点击或输入 **【复盘最近一次跑步】**（或随手上传手表截图），即可享受全自动科学复盘。
