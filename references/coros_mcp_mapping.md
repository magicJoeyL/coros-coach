# 高驰（COROS）MCP 接口与科学训练体系对齐映射手册 (全维度扩展版)

本手册定义了 **高驰（COROS）MCP 配置接入指南**、**EvoLab 运动体能体系、睡眠监测与全天健康指标** 与 **Jack Daniels VDOT / Pete Pfitzinger 科学训练体系** 的深度映射对照标准，并规范了在 Workbuddy / AI 环境中调用 **COROS MCP** 工具的核心契约与数据流。

## 0. 高驰（COROS）官方 MCP 接入指南（远程 HTTP + OAuth 授权）

在技能安装后的首次交互时，AI 教练需**优先引导跑者完成 COROS 官方 MCP 的接入**。

> **核心要点**：高驰 MCP 是官方提供的**远程 HTTP 端点 + OAuth 2.0 浏览器授权**服务。**不需要安装任何 npm 包（如 `@coros/mcp-server` 不存在），不需要将账号密码明文写入配置文件**。所有认证均通过浏览器弹窗安全完成。
> 官方指南：https://support.coros.com/hc/en-us/articles/50841795180948

### ① 各区域官方 MCP 端点

| 区域 | 端点 URL | 适用账号 |
|---|---|---|
| 🇨🇳 **中国区** | `https://mcpcn.coros.com/mcp` | 中国大陆注册的高驰账号 |
| 🌎 **北美 / 全球区** | `https://mcpus.coros.com/mcp` | 北美及其他地区注册的高驰账号 |
| 🇪🇺 **欧洲区** | `https://mcpeu.coros.com/mcp` | 欧洲区注册的高驰账号 |

### ② 接入方式（以本技能内置连接器为准）

> **⚠️ 重要事实**：多数客户端的「插件 / 连接器」市场**并未上架 COROS**，让跑者去搜索只会白找一场。**不要这样引导。**
> 正确做法：本技能自带 `scripts/connect.py`，它会自动完成「后台服务 + 公网隧道 + OAuth 动态注册 + PKCE 校验」，跑者只需点一条链接登录授权。

**A. 标准路径（所有客户端通用，推荐）**：
```bash
python3 scripts/connect.py --serve      # 输出 [AUTH_URL]，把链接发给跑者
```
跑者点开链接 → 登录高驰账号 → 同意授权 → 页面显示他自己的昵称与最近一次跑步 → 完成。无需填任何配置、密码、回调地址。

**B. 进阶：客户端自身支持 OAuth 型远程 MCP 时**（如 Cursor / Claude Code）：
```json
{
  "mcpServers": {
    "coros": { "type": "http", "url": "https://mcpcn.coros.com/mcp" }
  }
}
```
*前提：该客户端能对远程 MCP 发起 OAuth 授权并接收回调。WorkBuddy 客户端自带的「自定义连接器」入口是否支持，需实测；不支持时脚本路径永远可用。*

### ③ 认证与连通性自检
- 自检：`python3 scripts/connect.py --check`
- `[OK] 连接可用` → 已连通，静默继续
- `[NO_TOKEN]` / `[EXPIRED]` → 走 ② 的 A 路径重新授权
- 不要用「工具不存在」来判断失败——客户端的原生工具列表里本来就没有 COROS 工具，数据一律通过脚本读取

### ④ 截图兜底保障
若跑者暂无高驰账号或暂未配置 MCP，提示跑者直接发送手表详情截图，系统将通过多模态视觉引擎无缝解析，不阻断使用。

## 2. COROS MCP 核心工具接口与全维度指标扩展

高驰生态不仅包含跑步本身的数据，还完整记录了前夜睡眠、全天日常活动、交叉负荷与身体恢复状态。以下为核心 MCP 工具规范：

| 工具名称 | 触发时机 | 关键输出参数 | 业务与生理学用途 |
|---|---|---|---|
| `querySportRecords` | 复盘请求、周总结、排课前 | `activity_id`, `start_time`, `sport_type`, `distance_m`, `duration_s`, `avg_pace_s_per_km`, `avg_hr`, `max_hr`, `training_load`, `location_info` | 锁定最新跑步概览，获取起跑时间、经纬度及总负荷 TL |
| `getActivityDetail` | 深入复盘单次跑步/间歇/LSD | 分段数据 `laps[]` (配速、心率、步频、步幅、爬升/下降、功率、触地时间 GCT、垂直步幅比)、`aerobic_te`, `anaerobic_te` | 获取单公里/冲刺分段的微观动态，支撑六维运动生物力学诊断 |
| **`querySleepOverview`** *(新增重点)* | **单次复盘与排课必调** | `sleep_date`, `total_sleep_min`, `deep_sleep_min` (深睡), `rem_sleep_min` (快速眼动), `light_sleep_min`, `awake_min`, `sleep_score` (0-100), `sleep_hr_avg`, `sleep_hrv_deviation` | **分析前夜睡眠质量**：评估中枢神经系统恢复，判断当日心率上浮是否为熬夜或深睡不足所致 |
| **`queryDailyHealthData`** *(新增重点)* | **日常负荷与交叉运动** | `date`, `steps`, `active_calories`, `resting_hr` (晨间静息心率), `all_day_hrv`, `cross_training_load` (骑行/力量/游泳负荷), `daily_training_load_total` | **追踪全天非跑步负荷**：识别生活走动劳累、力量课疲劳，避免单看跑量而忽视隐性消耗 |
| **`queryRecoveryStatus`** *(新增重点)* | **课表微调与伤病预警** | `recovery_percentage` (0-100%), `recovery_time_remaining_hours` (完全恢复剩余小时), `stamina_remaining` (体能电量), `body_energy_level` | **实时体能电量评估**：确定当前是否适合开启高强度间歇或长距离 |
| `queryFitnessAssessmentOverview` + `queryTrainingLoadAssessment` | 周总结、赛季规划、能力评估 | `VO2max` / `Running Level` / `Threshold Pace` / 5K·10K·半马·全马预测成绩；`Short-Term Load` / `Long-Term Load` / `Load Ratio` / `Comment` | 评估有氧能力、预测成绩与长短期负荷平衡；当前字段名以 `python3 scripts/connect.py --tools` 实测为准 |

> **2.3.1 字段契约核对**：2.3.0 曾把 `running_performance`（跑力 0-100）、`base_fitness`、`load_impact`、`form`、`fatigue_trend` 写成 MCP 返回字段，**实测 API 并不返回这些名字**。上表已按实测结果更正。本手册第 4/5/6/7 节的跑力↔VDOT、CTL/ATL/TSB、6 分区、TE 对照表属于训练学概念与经验映射，不是 API 字段契约，使用时不要当作接口返回值去读取。任何字段不确定时以 `--tools` 与 `--call` 的实际输出为准，严禁编造字段名。

## 3. 前夜睡眠与全天负荷在训练复盘中的生理学印证逻辑

在单次跑步复盘（Route A）和周课表排定（Route B）中，**前夜睡眠与日间身体底色必须作为核心自变量纳入分析**：

### ① 前夜睡眠对当日跑步表现的影响判定
- **深睡时长与占比（Deep Sleep）**：
  - 正常标准：深睡占总睡眠 15%-25%（通常 ≥ 60-90 分钟），生长激素分泌与骨骼肌修护的主阵地；
  - **异常特征**：深睡 < 45 分钟，或睡眠评分 < 65 分：
  - **教练裁决**：跑者处于“中枢神经未完全恢复”状态。在同等配速下，交感神经处于代偿兴奋，心率偏高 3-6 bpm，自觉努力程度（RPE）显著升高；**绝不应将心率偏高归咎于“耐力退步”**。
- **睡眠平均心率与晨脉（Resting HR）**：
  - 若前夜睡眠平均心率或今晨静息心率较 7 天基准偏高 ≥ 4-5 bpm：典型自主神经系统应激信号（可能由饮酒、晚睡、消化负担或体内微炎症导致），提示当日严禁冲刺极限间歇。
- **睡眠 HRV 偏差值（HRV Deviation）**：
  - 睡眠 HRV 显著低于个人基线（跌破 1 个标准差）：交感神经占主导，迷走神经受抑，心血管顺应性变差，后半程心率漂移容易提前出现。

### ② 全天活动与交叉训练负荷（Non-Running Load）
- **隐形体能消耗**：若当日跑步前步数已达 15,000+ 步，或前一天有重度下肢力量训练（深蹲/硬拉）：
  - 跑步过程中步频易下降、触地时间（GCT）延长、垂直振幅增大；
  - 教练在诊断技术与跑姿时，应主动指出下肢肌肉预疲劳，避免机械判定为“跑姿退化”。

## 5. 高驰 EvoLab 体能模型与负荷监控映射

高驰采用与 Banister 冲量反应模型一致的双参数指数加权体系：

> **2.3.1 契约说明**：下表是**训练学概念映射**（CTL / ATL / TSB 类比），不是 COROS MCP 的返回字段。MCP 侧对应的是 `Short-Term Load` / `Long-Term Load` / `Load Ratio` / `Comment`；不要按 `Base Fitness` / `Load Impact` / `Form` 去解析接口数据。表内区间与阈值保持原文，属经验规则。

| 高驰指标 | 概念定义 | 科学训练体系对应 (Banister / Coggan) | 状态解读与教练应对策略 |
|---|---|---|---|
| **体能储备 (Base Fitness)** | 过去 42 天训练负荷的指数加权平均值 | **CTL (Chronic Training Load)** 长期体能 | 衡量跑者的“有氧底子”。若近期持续平稳爬升，说明基础吸收良好；单周爬升幅度建议 ≤ 5-8 点，严防盲目加量。 |
| **疲劳度 (Load Impact)** | 过去 7 天训练负荷的指数加权平均值 | **ATL (Acute Training Load)** 短期疲劳 | 反映短期高负荷冲击。连续 3 天高于 Base Fitness 40% 以上，即触发防过载预警。 |
| **体能状态 (Form)** | `Base Fitness - Load Impact` 的差值 | **TSB (Training Stress Balance)** 训练应激平衡 | 评估跑者当前是“生龙活虎”还是“精疲力竭”的核心晴雨表。 |

### 体能状态（Form）评估区间对照表

- **极佳（Fresh: +5 ~ +15）**：疲劳已消除，超量恢复显现。**适合比赛日、马拉松破 PB 或高强度间歇考核**。
- **良好（Optimal: -10 ~ +5）**：体能稳步提升，疲劳在正常耐受区间。**黄金训练窗口，可执行正常课表与长距离 LSD**。
- **疲劳（Fatigued: -30 ~ -10）**：身体处于高负荷吸收期。**次日必须安排 E 跑（轻松跑）或交叉休息，禁止连续安排重度课表**。
- **过度负荷（Overreaching: < -30）**：严重透支，免疫抑制与伤病发生率激增。**教练介入：强制休息或下调下周课表 30%-50%**。

## 6. 高驰 6 个心率区间与原版 5 个区间的精准映射

高驰手表默认采用以**乳酸阈值心率（LTHR）**为基准的 6 分区系统。在解析 COROS MCP 单圈数据与配速建议时，严格按以下映射规则换算至原版 Daniels 5 区间（E/M/T/I/R）：

| 高驰区间名称 | 高驰区间代码 | 阈值心率比例 (% LTHR) | 原版 Daniels 体系映射 | 训练目的与生理刺激 |
|---|---|---|---|---|
| **恢复区间 (Recovery)** | Zone 1 | 50% - 68% LTHR | **E 跑下限 / 极慢排酸跑** | 促进血液循环、加速代谢废弃物清除，体感极度轻松 |
| **有氧耐力 (Aerobic Endurance)** | Zone 2 | 69% - 84% LTHR | **E 跑 (Easy Aerobic Base)** | 毛细血管增生、线粒体密度增加、脂肪氧化供能主力区间 |
| **有氧动力 (Aerobic Power)** | Zone 3 | 85% - 95% LTHR | **M 跑 (Marathon Pace)** | 马拉松比赛专项配速，培养肌耐力与糖原节约能力 |
| **阈值区间 (Threshold)** | Zone 4 | 95% - 105% LTHR | **T 跑 (Threshold / 乳酸门槛)** | 乳酸生成与清除达到平衡，提升抗乳酸能力与 LT 配速 |
| **无氧动力 (Anaerobic Power)** | Zone 5 | 106% - 120% LTHR | **I 跑 (VO2max Intervals)** | 最大摄氧量刺激、心肌收缩力与泵血量提升，间歇跑核心 |
| **无氧耐力 (Anaerobic Endurance)**| Zone 6 | > 120% LTHR | **R 跑 (Repetitions)** | 神经肌肉募集效率、跑步经济性（Running Economy）、无氧冲刺 |

## 7. 高驰训练效果（Training Effect, TE）对齐

COROS MCP 返回的 `aerobic_te` 与 `anaerobic_te`（取值范围 0.0 - 5.0），直接用于评判课表执行是否“跑对目的”：

| TE 分值范围 | 高驰效果判定 | Daniels 课次目标达标校验准则 |
|---|---|---|
| **0.0 - 0.9** | 几乎无刺激 | 仅适用于 15-20 分钟极轻微排酸放松走/慢跑 |
| **1.0 - 1.9** | 轻度刺激 / 维持 | 适合日常短距离 E 跑（30-40 分钟）或恢复跑 |
| **2.0 - 2.9** | 良好维持 / 适度发展 | 60-75 分钟标准 E 跑，或周中渐进跑，有氧基础夯实 |
| **3.0 - 3.9** | 显著提升 (Optimal) | **标准周中质量课（T 跑 / I 跑）或周末长距离 LSD 的理想目标值** |
| **4.0 - 4.9** | 高度刺激 / 深度疲劳 | 模拟赛、全马专项长距离大课、高难度长组间歇，需 48h 深度恢复 |
| **5.0** | 极限过度 (Overreaching) | 偏离日常训练计划，警惕伤病与过度训练，严禁连续出现 |
